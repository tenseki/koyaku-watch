# MVP集計グラフ

- `MVP_23政策_言及率_全487投稿.svg`：Web・GitHub・印刷用のベクター版
- `MVP_23政策_言及率_全487投稿.png`：note・SNS等に貼り付ける1600×1400px版

23政策すべてについて、具体策言及率、政策方向以上の言及率、発信アカウント数を示す。0件の政策も省略しない。

`data/mvp_policy_summary_2026.csv`からSVGを再生成する場合は、次を実行する。

```bash
python3 scripts/render_mvp_policy_chart.py
```

## 全候補者集計グラフ

- `全候補者_23政策_政策言及内訳_197投稿.svg`：23政策に言及した197投稿を分母に、具体策・政策方向・分野のみを分けて示すベクター版
- `全候補者_23政策_政策言及内訳_197投稿.png`：上記のPNG版

全投稿に占める割合ではなく、23政策への言及が確認できた投稿の中で、どの項目がどの程度現れたかを読むための図である。1投稿が複数政策に触れうるため、政策別の割合の合計は100%にならない。

SVGは次で再生成できる。

```bash
python3 scripts/render_all_candidates_policy_chart.py
```
