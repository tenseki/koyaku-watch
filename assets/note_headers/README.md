## シリーズ共通の見た目

- 画面全体を、使い込んだ普通の木の机で埋める。
- 左側の小さな関節式ランプを、調査を一緒に行う無言の相棒として毎回登場させる。
- ランプに顔や手足は付けず、資料を覗き込む姿勢だけで人格を出す。
- 灰皿、筆箱、鉛筆、カード、比較表など、複数の道具と情報源を示すものを置く。
- 生成り、チャコールグレー、灰青、くすんだ赤を中心とした低彩度の配色にする。
- 写実に寄せすぎず、輪郭線と印刷物の粒子感がある雑誌挿絵にする。
- 政治家の顔、党章、国旗、投票箱、拳、メガホン、AI回路などの直接的な記号は使わない。
- 画像内に読める文字や意味のない疑似文字を入れない。

## 各回で変えるもの

中央の資料と道具の組み合わせを、その回の内容に合わせて変える。机、ランプ、配色、画材感は固定する。

資料を真正面に整列させすぎず、中心のノートや冊子を少し斜めに置く。見ている人とランプが、同じ資料を一緒に覗き込んでいる柔らかい印象を残す。

灰皿を、文字を使わない小さな連番記号にする。第0回では空のままにし、回が進むごとに吸い殻を増やす。煙や喫煙している人物は描かず、作業の進行と蓄積だけを示す。
