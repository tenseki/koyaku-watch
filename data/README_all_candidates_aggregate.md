# 全候補者版・公開集計データの説明

このフォルダの全候補者版集計は、229候補・7,758投稿について、人手確認済みの投稿単位ラベルを匿名で集計したものである。投稿本文、投稿ID、投稿URL、アカウント名・ID・ハンドル、投稿単位のラベル、AI提案、確認者メモは含めない。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `all_candidates_policy_summary_2026.csv` | 23政策ごとの投稿件数、投稿比率、候補者数 |
| `all_candidates_analysis_summary_2026.json` | 全体件数、ラベル件数、候補者への分布、投稿種別別の集計 |
| `researcher_rule_patterns_2026.csv` | 研究者が定めた判定パターンと境界事例の台帳 |

## 政策別CSVの列

| 列 | 意味 |
| --- | --- |
| `policy_id` / `category` / `policy_title` | 事前に固定した政策項目の識別子、分類、名称 |
| `specific_measure_posts` | 具体的な制度名、対象、手段、数値目標などから個別項目を特定できた投稿数 |
| `specific_measure_density` | 上記投稿数を全7,758投稿で割った値 |
| `policy_direction_posts` | 個別項目に対応する方向性を確認できたが、具体策には至らない投稿数 |
| `direction_or_more_posts` / `direction_or_more_density` | 具体策と政策方向を合わせた投稿数、および全7,758投稿に対する比率 |
| `topic_only_posts` | 政策分野に触れるだけで、個別項目や方向性を特定できない投稿数 |
| `specific_measure_candidates` / `direction_or_more_candidates` | 各区分を発信した候補者数。投稿回数とは別の広がりの指標 |
| `candidate_count` | 分析対象の候補者数（229） |

1投稿が複数政策に触れることがあるため、政策別投稿数や比率を横に合計して、全投稿数や100%と比較してはならない。

## 全体JSONの読み方

- `posts` は、投稿を一度ずつ数えた集計である。たとえば複数政策に触れる投稿も「政策言及あり」としては1投稿で数える。
- `label_assignments` は、政策ラベルの件数である。したがって投稿数より大きくなりうる。
- `candidate_breadth` は、言及が候補者間にどれだけ広がったかを示す。候補者を特定できる情報は含めない。
- `post_types` は通常投稿、返信、引用投稿別の件数であり、単純リポストは対象外である。

このデータが示すのは、設定した期間・候補者群・23政策について、候補者名義のX投稿本文にどのような言及が現れたかである。投稿の到達量、画像・動画内の情報、他媒体での発信、候補者本人の内心は対象外である。
